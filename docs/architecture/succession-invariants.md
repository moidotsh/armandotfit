# What survives every thesis

> Nine theses in four months (logbook → signal → count → broadsheet →
> quiet page → board → gauge → scoreboard → …). Each successor killed
> its predecessor's cleverest parts — and a small core survived every
> single time, not by sentiment but because each pass re-derived it
> from the same three facts: one user, mid-set, at arm's length. This
> page is that core, promoted from the kept-lists so the tenth
> upending starts from law instead of archaeology. Kill any of it —
> but only on an argument that answers these facts better.

## The product core
1. **The armed-set model** — draft set rows exist only once logged;
   hydration creates zero rows. Pre-armed values, carry-forward, and
   one-tap LOG. Speed IS the product; every thesis converges here.
2. **The rest countdown's behavior** — starts at LOG, ±15, dismiss,
   settle. (Its FORM changed three times; the behavior never did.)
3. **Computed-at-read everything** — progression derived from raw
   immutable history; nothing precomputed, ever.
4. **The program in TypeScript** — the prescription is code; the
   database stores facts, not plans.
5. **Coarse identity + tags** — the three-question test and the
   promotion rule.
6. **Stack-from-home + the ticker** — no tab bar; the live session
   stays one tap away on every Desk page.

## The design method (the visionless law)
7. **One statement per screen + countable budgets** — sizes, inks,
   rules, interactives; probed in DOM, both modes.
8. **Caps furniture, sentence-case content** — every thesis's print
   discipline.
9. **Contrast computed from hexes, never felt** — the matrix recomputes
   at gate time (`scripts/verify-design.ts`).
10. **The 490px law, the 44px floor, the desktop column** — geometry,
    not taste.
11. **Math before pixels** — ratios, budgets, and WCAG arithmetic are
    decided before any token is written; probes are the eyes
    (computed style → geometry → pixels, in that order).
12. **Deletion answers drift** — when the owner asks for less, the
    answer is a removed element, never a restyled one.

## The chassis
13. **The 13-audit + tsc + tests gate on every commit** — the audits
    are canonical; extend, never weaken.
14. **The mirror trio + the shell relationship** — index.html, the
    injector, the runtime block; consumer↔shell sync is a reviewed
    act (`scripts/check-shell-drift.ts` and its committed baseline).
15. **One thesis doc as compass**, retired with a succession note —
    theses die by argument; the record stays.
