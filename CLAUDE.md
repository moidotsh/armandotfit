# armandotfit

> armandotfit is a personal fitness PWA — the AM/PM hypertrophy program, coarse exercise identities, tag-based realization context, and computed-at-read progression — built on [arqavellum](../arqavellum) (the public PWA-first starter shell). Theme: **THE GAUGE — the gym's instrument panel: machined enamel panels on concrete, loads on the printed pin rail, figures on rolling counters, the clock as a first-class instrument (elapsed + the rest countdown), one signal hue, the verb is the heaviest ink** (see `docs/architecture/gauge-thesis.md`).

This file is the repo-level operating context for Claude Code sessions at the armandotfit root. It auto-loads. Read the relevant section before landing any armandotfit change.

**The greenslate rebuild (2026-10)** replaced the prior Phase 1–6 schema (program templates, user plans, eligibility, capability inventory, presets, trigger-maintained analytics — 34 tables) with a five-table logging core. That machinery is deleted, not dormant; git history preserves it. Docs describing it are superseded by this file.

## Invariants

Load-bearing rules that aren't obvious from the code:

1. **Bun only.** Never commit `package-lock.json` or `yarn.lock`. `audit-pattern-compliance.ts` (S19) enforces this.

2. **PWA-first, two-layer delivery.** Web static export is the supported default; native is a consumer extension (scaffolding + `assets/*` PNGs ship; a native release still needs real bundle IDs + platform validation). PWA tags + id'd styles reach the deployed HTML twice: `scripts/inject-critical-web.ts` (chained into `build:web`/`vercel-build`, copies them into every exported route) and the runtime injection in `app/_layout.tsx` (covers dev + anything the export strip misses). `index.html` is the declaration both mirror — keep the three in sync. The **ink boot plate** (id'd `<style>` in `index.html`, lifted by `markBootReady()`) is part of this set. Barrel shims (`shims/`, regenerated by `scripts/sync-barrel-shims.ts` before every expo command, enforced by `audit-shim-sync.ts`) keep icon/date-fns imports from pulling whole libraries; production exports stub `app/dev/*` (gated on `EXPO_PUBLIC_DEV_SURFACES`, set by `start`/`web`). Run `bun run verify:web-build` after touching export plumbing.

3. **THE GAUGE theme — light default, dark opt-in, one dialect declaration, the wire, the drawn figures, the rest instrument.** `constants/theme.ts` sets `DIALECT = 'ink'` (flat atmosphere, chit toasts, curtain transitions — the drawer primitive stays synced but unwired: THE GAUGE has NO tab bar; the Desk is a stack from home's jump lines, and the **ticker** (`components/composed/SessionStrip.tsx`, mode-following plate with the LIVE pulse in signal) pins under every Desk header while a session runs — one tap returns to the Floor). Two palettes: **ENAMEL** (light, concrete ground `#EBEDEA` + enamel panels `#FCFDFB`) and **NIGHT GYM** (dark, `#0D0F11` + lit panels `#171A1F`) — both cool-NEUTRAL; the live **Floor follows the mode**, and `colors.focus.*` is **the wire**: mode-independent near-black `#0B0D0F` for the chit and the curtain ONLY. **Loads live on the pin rail** (`constants/gauge.ts` — the rail math): every load magnitude renders as a printed tick scale with the pin at the load (`components/composed/PinRail.tsx`; `railMaxFor` rounds up to the next 25 — the ceiling is auto-ranging and STICKY: it grows to cover, never shrinks mid-session; probe: proportional + monotone within a fixed ceiling); set counts render as pip groups of five (`components/composed/SetPips.tsx`, the live pip breathing signal); digits live only in the logger's rolling counters (`components/composed/RollingCounter.tsx` — the odometer rolls ONLY on user-driven changes; clocks never animate), the ledger rows, and figure-statements. Statuses flip (`components/composed/FlipTile.tsx` — NOW/NEXT/DONE·n). **THE REST INSTRUMENT** (`stores/restStore.ts` + `hooks/useRestClock.ts`): after every LOG SET a rest countdown runs (default 90s, persisted UI preference — the Settings panel row; ±15 steppers; tap to dismiss; nothing joins the schema). One SIGNAL hue: brand fill `#C23A00` light / `#FF8A3D` dark with measured companions (`brandText`, `textOnBrand`); it appears exactly as the record mark, links/selection, and the live pulse (the rest countdown while running) — the verb does NOT use it (**the verb is ink**: `buttonBackground` = text ink with the ground label, 17.8:1/16.6:1 measured; the shell's `MobilePrimaryButton` reads `buttonBackground` as its accent). The `colors.*.meter` ramp is the ZONE ramp (barbell/dumbbell/cable/machine/bodyweight + steel — the gym's geography; structure synced with arqavellum which keeps its own values); it colors the library's zone lines and the swap bench's ticks. Elevation law: the room is flat — panels sit on concrete with a 1px steel hairline (radius 2); the ONE real shadow is `mobilePremium.instrumentShadow` on the docked logger (`components/composed/TheLogger.tsx`) — the app's single physical object. **The hierarchy law:** exactly one statement per screen (36px Instrument Cond), second voice ≥1.4× quieter, ≤4 distinct sizes and ≤4 text colors per screen, one verb — with the air law (32px block rhythm, 24px statement halo, 20px gutter) and the rule budget (≤3 hairlines + at most one 2px rule — the day panel's instrument face). **Furniture is authored in CAPS (≤3 words); content speaks.** Type: **Instrument Sans** (one variable woff2, wght+wdth; `Instrument Cond` = the same file with `font-stretch: 75%` pinned — one download, two families) + **Martian Mono** (every figure; `mobileCounter` is the mono face's one display size, 56) + platform sans for body; six sizes (56 · 36 · 21 · 17 · 15 · 11). Motion: the mechanical family only — THE FLIP (110ms), THE ROLL (140ms), THE PIN DROP (120ms), all post-interactive + scroll-linked F4 compress (`useCompressFade`) + the shell curtain; time-driven figures never animate; reduced motion collapses everything to static. `audit-ui-theme.ts` (S7) bans hardcoded hex. Icon surfaces (`public/icons/*`, `assets/*`) are ember/ink barbell marks — regenerate, don't hand-edit.

4. **Five tables exactly.** `users` (one row per lifter: display name, `weight_unit`, `rest_days` — picker config), `exercises` (coarse identity: `user_id NULL` = system seed row, name is the natural key), `sessions` (`started_at`, `split_day` nullable, note; AM and PM are two rows), `logged_exercises` (`tags text[]` — the ONLY context mechanism), `logged_sets` (`reps` + `weight` + note — **a row is a completed set**; no completion flags, no target columns). Adding a sixth table or a context column is a design decision, not a convenience — take it to the owner first. The migration pair `supabase/migrations/20261001000000_greenslate_rebuild.sql` (+ `20261001000001_grants.sql`, the role-grant companion — tables without grants are unreachable past Supabase's schema privileges) is the canonical schema (drop-and-recreate; applying to the live project is approval-gated).

5. **Computed, never stored.** Streaks, PRs, weekly buckets, day-of-split suggestions — all derived at read time from raw sessions (`progressionService`, `analyticsService`, `getNextSplitDay`). No triggers, no aggregate tables, no cached progression values anywhere. If a read is slow, index the raw tables; don't precompute. **The weight DISPLAY unit is the same law:** `users.weight_unit` (`'kg' | 'lb'`, the Settings panel row) converts every digit-bearing read via `utils/weight.ts` — storage is and stays KILOGRAMS, steppers step 2.5 kg / 5 lb, the Floor's armed values live in display units and cross into kg at `addSetToDraft` (the one conversion boundary), and the rails are unit-invariant (ratios).

6. **History is immutable raw fact.** No rewrites of `sessions`/`logged_exercises`/`logged_sets` (adding a NEW nullable column in a migration is fine). The only FK from history is `logged_exercises.exercise_id → exercises` (RESTRICT — identity is stable). Vocabulary lives in TS, never in CHECK constraints — the DB stores TEXT/tags so the vocabulary extends without migrations.

7. **Exercise identity is coarse; realization is tags.** A separate identity exists only when the distinction passes the three-question test: (a) decided before the gym, (b) named differently without thinking, (c) mixing trajectories would mislead. Everything else — grip, attachment, machine, stance, execution style — is a tag on `logged_exercises`. Suggested tags ride the program slots (`SplitSlot.suggestedTags`) and pre-fill the draft; free-form tags autocomplete from `TAG_VOCABULARY_SEED` + the user's own history. **Promotion rule:** a tag becomes a column/registry only after (a) ≥10 consistent uses AND (b) the same filter/comparison was attempted twice and free-text couldn't answer it.

8. **The program is TypeScript, never the database.** `shared/exercises/splits.ts` holds the AM/PM split (4 days × AM/PM × 4 slots + the one-a-day compression), each slot carrying coarse exercise key, suggested tags, and the programmed Rx (`sets [min,max]`, `reps [min,max]`). `shared/exercises/data.ts` is the sole display source (42 entries: 26 split identities + 16 browsable extras; identity joins by NAME — entries sharing a name are the same exercise row). Session start hydrates the draft locally (`hydrateFromSplit` — no DB round-trip); save resolves names find-or-create. Adding a split exercise = `splits.ts` (ExerciseKey + slot) + `data.ts` entry + optional seed INSERT in the same change.

9. **Audit scripts are canonical.** If this file and `scripts/audit-*.ts` disagree, the scripts win.

10. **The 490px height-budget test** carries over. Any new screen fits iPhone SE compact without scrolling for the primary action. See `docs/architecture/mobile-premium-design-system.md`.

11. **Auth is email/password and the guard is ON.** `APP_LAYOUT.authGuard = true` in `constants/layout.ts` — every route walls except the auth screens (this app owns real per-user history; the starter's open posture does not apply). No PIN primitives.

## Pre-commit checks (read before committing)

Armandotfit has 13 structural audits + `tsc --noEmit` + structural ESLint on every `git commit` via `.husky/pre-commit`. Run them on the working tree **before** staging:

    cd armandotfit && bun run lint:structure && bunx tsc --noEmit

### The two universal escape hatches

- **`// <check>-exempt`** — suppresses one violation within a 300-char lookback. Use sparingly with a justification.
- **`git commit --no-verify`** — skips the hook entirely. Genuine emergencies only.

### The five that bite most often

1. **S5 barrels** — same-folder imports go relative; cross-folder go through the barrel. `bun run scripts/audit-barrels.ts --fix` auto-rewrites.
2. **C1 router calls** — only `navigation/NavigationHelper.tsx` (all calls now flow through the curtain seam) and `hooks/useAuthNavigation.ts`.
3. **S9 supabase** — no `supabase.*` outside `utils/supabase/*` / `services/*`.
4. **S7 hex colors** — never hardcode `'#E8590C'`; pull from `theme.colors.*` via `useAppTheme()` or a constants import.
5. **S11 console** — `logger` only.

## Arqavellum relationship

Direct-copy consumer of the public starter (sibling at `../arqavellum`, `github.com/moidotsh/arqavellum`). The shell — MobilePremium kit + showcase, audit scripts, PWA plumbing, provider stack, auth scaffolding, navigation helper, hooks — is copied file-by-file and re-synced when the shell evolves.

**Sync procedure:** copy the relevant files from `../arqavellum/`, then re-apply armandotfit's overrides — `constants/theme.ts` (GAUGE palettes + zone-ramp meter values + `DIALECT = 'ink'`; the structure comes from the shell, only the values and the dialect pick are ours), `constants/displayName.ts`, `constants/layout.ts` (`authGuard: true`), icon assets, `index.html` (GAUGE theme-colors + boot plate + the three `@font-face` declarations), the domain routes in `NavigationHelper.tsx`, `navigation/routeMetadata.ts`. Copy the kit WHOLE (the showcase is the visual source of truth and demos every primitive) but wire into app routes only what this app uses. Currently synced-but-unwired: i18n harness + `LangToggle`, `MobileAbsorbBar`, `MobileAnnouncementBar`, `MobileFootnote`, `CheckBox`, `Wizard`/`MobileStepper`, `ScreenScaffold`. Shell-level bug fixes made here port back to arqavellum (public-repo discipline applies there — no consumer names in the public repo).
