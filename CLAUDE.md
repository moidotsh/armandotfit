# armandotfit

> armandotfit is a personal fitness PWA — the AM/PM hypertrophy program, coarse exercise identities, tag-based realization context, and computed-at-read progression — built on [arqavellum](../arqavellum) (the public PWA-first starter shell). Theme: **THE INTERVAL — the live figure owns the counter: the biggest mark on a screen is the figure answering its current question (the rest clock while rest runs, the armed expression otherwise — exchanged by repaint), every quantity a printed tabular numeral (nothing drawn), ink is state (armed/live full ink, settled/unarmed muted), one ground + rules and air (no panels, radius 0, zero shadows), one RED INK strictly record/link/live (furniture never wears it), the harmonic ramp {12, 18, 36, 72}, the one-field logger, THE STILL SYSTEM + the re-weight (no content motion), the verb is the heaviest ink** (see `docs/architecture/interval-thesis.md`).

This file is the repo-level operating context for Claude Code sessions at the armandotfit root. It auto-loads. Read the relevant section before landing any armandotfit change.

**The greenslate rebuild (2026-10)** replaced the prior Phase 1–6 schema (program templates, user plans, eligibility, capability inventory, presets, trigger-maintained analytics — 34 tables) with a five-table logging core. That machinery is deleted, not dormant; git history preserves it. Docs describing it are superseded by this file.

## Invariants

Load-bearing rules that aren't obvious from the code:

1. **Bun only.** Never commit `package-lock.json` or `yarn.lock`. `audit-pattern-compliance.ts` (S19) enforces this.

2. **PWA-first, two-layer delivery.** Web static export is the supported default; native is a consumer extension (scaffolding + `assets/*` PNGs ship; a native release still needs real bundle IDs + platform validation). PWA tags + id'd styles reach the deployed HTML twice: `scripts/inject-critical-web.ts` (chained into `build:web`/`vercel-build`, copies them into every exported route) and the runtime injection in `app/_layout.tsx` (covers dev + anything the export strip misses). `index.html` is the declaration both mirror — keep the three in sync. The **ink boot plate** (id'd `<style>` in `index.html`, lifted by `markBootReady()`) is part of this set. Barrel shims (`shims/`, regenerated by `scripts/sync-barrel-shims.ts` before every expo command, enforced by `audit-shim-sync.ts`) keep icon/date-fns imports from pulling whole libraries; production exports stub `app/dev/*` (gated on `EXPO_PUBLIC_DEV_SURFACES`, set by `start`/`web`). Run `bun run verify:web-build` after touching export plumbing.

3. **THE INTERVAL theme — light default, dark opt-in, one dialect declaration, the wire, the live figure, the rest instrument.** `constants/theme.ts` sets `DIALECT = 'ink'` (flat atmosphere, chit toasts, curtain transitions — the drawer primitive stays synced but unwired: THE INTERVAL has NO tab bar; the Desk is a stack from home's jump lines, and the **ticker** (`components/composed/SessionStrip.tsx`, LIVE in RED INK + the elapsed figure) pins under every Desk header while a session runs — one tap returns to the Floor). Two palettes: **THE PRINTED CARD** (light, one warm ground `#F4F2EE`) and **THE UNLIT BOARD** (dark, `#161412`) — both WARM-neutral; `card` = the ground (the panel tier is dead — a card is the ground plus a rule), `colors.focus.*` is **the wire**: mode-independent near-black for the chit and the curtain ONLY. **THE LIVE FIGURE OWNS THE COUNTER** (`docs/architecture/interval-thesis.md` §2, §7): at most one figure rides the counter rank (72) per screen — the figure answering the screen's current question. On the Floor it is STATE-DEPENDENT: at LOG the rest clock takes the counter (72 mono, red — the live pulse; ±15 steppers flanking; the figure itself the dismiss target) while the armed expression demotes to the statement rank (36 mono, muted; the armed field at 500 keeps its 2px rule against the unarmed 400); at settle the expression re-weights back to 72/700 ink and recovery collapses to the quiet row. **The exchange is THE RE-WEIGHT — a pure repaint** (probe-verified: no transform changes across it). **INK IS STATE:** armed/current/live carry the full ink (the unarmed logger field demotes to 400/muted against the armed 700/ink in work — three countable signals: rule, weight, ink); settled/past/unarmed read muted. **THE RULED ROW** (`components/composed/RegisterLine.tsx` — name left · air · right-aligned mono figure) is the app's one repeating composition (the incumbent's leader dots are deleted — the air is the leader). The logger is **THE ONE-FIELD INSTRUMENT** (`components/composed/TheLogger.tsx`): one armed expression, ONE shared stepper pair stepping it by its own step, tap to arm, tap again to type; its one-tap log behavior is pinned by tests. **THE REST INSTRUMENT** (`stores/restStore.ts` + `hooks/useRestClock.ts`): after every LOG SET a rest countdown runs (default 90s, persisted UI preference — the Settings row; per-exercise memory — a ±15 tune becomes that station's default; tap the readout to dismiss; red while running; nothing joins the schema). **ONE RED INK, STRICTLY THREE JOBS** (the `brand` slot, `#BE2B20`/`#FF6B5E`): the RECORD mark (PRs, the streak, the bests, the record week, the number-to-beat FIGURE — never its label), links/selection, and the LIVE pulse (the rest clock running, the ticker, today in the grid); **furniture never wears it** (the home window whisper and the 404 lost the incumbent's loans); the verb does NOT use it (**the verb is ink**: `buttonBackground` = text ink, 15.7:1/15.3:1 with its label). The `colors.*.meter` ramp is the ZONE ramp (barbell/dumbbell/cable/machine/bodyweight + steel — data encoding, not identity). Elevation law: **zero shadows, radius 0 everywhere** (the square cut); the logger docks under the screen's one 2px rule; the Floor's board is hairline + rows ONLY (MAP is its one toggle — words only). **THE HARMONIC RAMP:** every typography size ∈ {12, 18, 36, 72} (each divides 72), lineHeight = size + 6, **tracking authored per rank and exact** (counter −1.5 · statement −0.5 · row 0 · caps furniture +0.8 — a closed set), at most three text sizes per screen (+ the counter where the thesis assigns one), one statement per screen (36 Space Grotesk, sentence case), second voice 2.0× quieter, ≤3 inks on the ground, ≤3 hairlines + one 2px rule, interactives ≤9 (Floor ≤12; repeated-row affordances count once per family). **The call-site law is gated:** no ad-hoc `fontSize`/`letterSpacing` literal anywhere in `app/`, `components/composed/`, `components/primitives/`, or the nine kit primitives this app renders (`scripts/verify-design.ts` scans source at gate time). **FURNITURE IS AUTHORED IN CAPS (≤3 words) in Martian 12; CONTENT SPEAKS** (sentence case, Space Grotesk). Type: **Space Grotesk** (words, one variable woff2) + **Martian Mono** (every figure) + platform sans for long reading; no condensed second family. **THE STILL SYSTEM:** no proprietary content motion — values swap, the re-weight re-ranks, clocks tick by repaint; the only motions are the shell curtain, the press opacity dip, and the sheet slide. `audit-ui-theme.ts` (S7) bans hardcoded hex. Icon surfaces (`public/icons/*`, `assets/*`) are ember/ink barbell marks — regenerate, don't hand-edit.

4. **Six tables — five logging tables exactly, plus the owner-sanctioned music picks.** The logging core: `users` (one row per lifter: display name, `weight_unit`, `rest_days` — picker config), `exercises` (coarse identity: `user_id NULL` = system seed row, name is the natural key), `sessions` (`started_at`, `split_day` nullable, note; AM and PM are two rows), `logged_exercises` (`tags text[]` — the ONLY context mechanism), `logged_sets` (`reps` + `weight` + note — **a row is a completed set**; no completion flags, no target columns). The sixth, `music_picks` (2027-01, owner-requested): raw picked tracks — **its surface was REMOVED 2027-01 (the owner plays music elsewhere); the table remains in the schema, untouched by any UI**; migration pair `20270120000000_music_picks.sql` + `20270120000001_music_picks_grants.sql`, RLS owner-only. Dropping it is a migration = owner sign-off. Adding a SEVENTH table or a context column is a design decision, not a convenience — take it to the owner first. The greenslate migration pair `20261001000000_greenslate_rebuild.sql` (+ `20261001000001_grants.sql`, the role-grant companion — tables without grants are unreachable past Supabase's schema privileges) is the canonical logging schema (drop-and-recreate; applying anything to the live project is approval-gated).

5. **Computed, never stored.** Streaks, PRs, weekly buckets, day-of-split suggestions — all derived at read time from raw sessions (`progressionService`, `analyticsService`, `getNextSplitDay`). No triggers, no aggregate tables, no cached progression values anywhere. If a read is slow, index the raw tables; don't precompute. **The weight DISPLAY unit is the same law:** `users.weight_unit` (`'kg' | 'lb'`, the Settings panel row) converts every digit-bearing read via `utils/weight.ts` — storage is and stays KILOGRAMS, steppers step 2.5 kg / 5 lb, the Floor's armed values live in display units and cross into kg at `addSetToDraft` (the one conversion boundary), and no figure ever converts behind its print.

6. **History is immutable raw fact.** No rewrites of `sessions`/`logged_exercises`/`logged_sets` (adding a NEW nullable column in a migration is fine). The only FK from history is `logged_exercises.exercise_id → exercises` (RESTRICT — identity is stable). Vocabulary lives in TS, never in CHECK constraints — the DB stores TEXT/tags so the vocabulary extends without migrations.

7. **Exercise identity is coarse; realization is tags.** A separate identity exists only when the distinction passes the three-question test: (a) decided before the gym, (b) named differently without thinking, (c) mixing trajectories would mislead. Everything else — grip, attachment, machine, stance, execution style — is a tag on `logged_exercises`. Suggested tags ride the program slots (`SplitSlot.suggestedTags`) and pre-fill the draft; free-form tags autocomplete from `TAG_VOCABULARY_SEED` + the user's own history. **Promotion rule:** a tag becomes a column/registry only after (a) ≥10 consistent uses AND (b) the same filter/comparison was attempted twice and free-text couldn't answer it.

8. **The program is TypeScript, never the database.** `shared/exercises/splits.ts` holds the AM/PM split (4 days × AM/PM × 4 slots + the one-a-day compression), each slot carrying coarse exercise key, suggested tags, and the programmed Rx (`sets [min,max]`, `reps [min,max]`). `shared/exercises/data.ts` is the sole display source (42 entries: 26 split identities + 16 browsable extras; identity joins by NAME — entries sharing a name are the same exercise row). Session start hydrates the draft locally (`hydrateFromSplit` — no DB round-trip); save resolves names find-or-create. Adding a split exercise = `splits.ts` (ExerciseKey + slot) + `data.ts` entry + optional seed INSERT in the same change.

9. **Audit scripts are canonical.** If this file and `scripts/audit-*.ts` disagree, the scripts win.

10. **The 490px height-budget test** carries over. Any new screen fits iPhone SE compact without scrolling for the primary action. See `docs/architecture/mobile-premium-design-system.md`.

11. **Auth is email/password and the guard is ON.** `APP_LAYOUT.authGuard = true` in `constants/layout.ts` — every route walls except the auth screens (this app owns real per-user history; the starter's open posture does not apply). No PIN primitives.

## Pre-commit checks (read before committing)

Armandotfit has 13 structural audits + `verify-design` (the design-law verifier: ramp arithmetic, the square cut, the wire, and the full WCAG matrix from `theme.ts` hexes — chained into `lint:structure`) + `tsc --noEmit` + structural ESLint on every `git commit` via `.husky/pre-commit`. Run them on the working tree **before** staging:

    cd armandotfit && bun run lint:structure && bunx tsc --noEmit

### The two universal escape hatches

- **`// <check>-exempt`** — suppresses one violation within a 300-char lookback. Use sparingly with a justification.
- **`git commit --no-verify`** — skips the hook entirely. Genuine emergencies only.

### The five that bite most often

1. **S5 barrels** — same-folder imports go relative; cross-folder go through the barrel. `bun run scripts/audit-barrels.ts --fix` auto-rewrites.
2. **C1 router calls** — only `navigation/NavigationHelper.tsx` (all calls now flow through the curtain seam) and `hooks/useAuthNavigation.ts`.
3. **S9 supabase** — no `supabase.*` outside `utils/supabase/*` / `services/*`.
4. **S7 hex colors** — never hardcode `'#E8590C'`; pull from `theme.colors.*` via `useAppTheme()` or a constants import.
5. **S11 console** — `logger` only.

## Arqavellum relationship

Direct-copy consumer of the public starter (sibling at `../arqavellum`, `github.com/moidotsh/arqavellum`). The shell — MobilePremium kit + showcase, audit scripts, PWA plumbing, provider stack, auth scaffolding, navigation helper, hooks — is copied file-by-file and re-synced when the shell evolves.

**Sync procedure:** copy the relevant files from `../arqavellum/`, then re-apply armandotfit's overrides — `constants/theme.ts` (INTERVAL palettes + zone-ramp meter values + `DIALECT = 'ink'`; the structure comes from the shell, only the values and the dialect pick are ours), `constants/displayName.ts`, `constants/layout.ts` (`authGuard: true`), icon assets, `index.html` (INTERVAL theme-colors + boot plate + the two `@font-face` declarations), the domain routes in `NavigationHelper.tsx`, `navigation/routeMetadata.ts`. Copy the kit WHOLE (the showcase is the visual source of truth and demos every primitive) but wire into app routes only what this app uses. Currently synced-but-unwired: i18n harness + `LangToggle`, `MobileAbsorbBar`, `MobileAnnouncementBar`, `MobileFootnote`, `CheckBox`, `Wizard`/`MobileStepper`, `ScreenScaffold`. Shell-level bug fixes made here port back to arqavellum (public-repo discipline applies there — no consumer names in the public repo).
